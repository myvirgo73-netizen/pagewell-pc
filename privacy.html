개인정보처리방침 및 서비스 약관

대상 서비스: Pagewell PC (Windows 데스크톱 앱)

1. 서비스 소개

Pagewell PC는 전자책을 읽고 서재를 관리하는 Windows 데스크톱 앱입니다.

2. 구글 연결과 요청하는 권한

구글 계정 연결은 선택 기능입니다. 연결하지 않아도 앱의 기본 기능을 사용할 수 있습니다. 연결하는 경우 요청하는 권한은 다음 세 가지뿐입니다.

  • drive.appdata: 앱 전용 숨김 폴더에 백업과 동기화 자료를 저장합니다. 이 폴더는 사용자의 다른 드라이브 파일과 분리되어 있습니다.
  • drive.file: 사용자가 직접 고른 파일만 앱으로 가져옵니다. 고르지 않은 파일에는 접근하지 않습니다.
  • drive.readonly: 서재의 "Google Drive 폴더 열기"를 누를 때만 사용합니다. 폴더와 파일 목록을 읽고, 사용자가 고른 책만 내려받습니다. 수정·삭제·업로드는 하지 않으며, 읽은 내용은 개발자 서버로 전송하지 않습니다.

3. 구글 사용자 데이터의 처리

  • 구글 데이터는 개발자 서버로 보내거나 저장하지 않습니다. 데이터는 사용자의 PC와 사용자 본인의 구글 드라이브 사이에서만 오갑니다.
  • 광고에 사용하지 않으며, 제3자에게 제공하거나 판매하지 않습니다.
  • 구글 로그인 토큰은 사용자의 PC에서 암호화해 저장합니다.
  • Pagewell PC가 구글 API 서비스에서 받은 정보를 다른 앱으로 이전하는 일은 앱의 기능 제공에 필요한 경우를 제외하고 없습니다.

4. Google API 서비스 사용자 데이터 정책 준수

Pagewell PC가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 준수합니다.

5. 연결 해제와 권한 취소

  • 앱 안에서 구글 연결을 끊을 수 있습니다.
  • 구글 계정의 https://myaccount.google.com/permissions 에서 Pagewell PC의 권한을 언제든지 취소할 수 있습니다.

6. 서비스 이용 약관

  • 사용자는 본인이 읽을 권리가 있는 파일에 한해 앱을 사용해야 합니다.
  • 앱은 현재 상태 그대로 제공되며, 기능은 사전 안내 없이 바뀌거나 종료될 수 있습니다.
  • 사용자의 PC와 구글 드라이브에 저장된 자료의 관리와 백업 책임은 사용자에게 있습니다.
